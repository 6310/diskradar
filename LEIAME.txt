================================================================================

Este pacote contem o codigo completo e os inicializadores prontos para o Windows
do Geio DiskRadar v2.2.0, ferramenta forense de leitura 100% segura (Read-Only)
para identificacao de carteiras de criptomoedas, sementes BIP-39, pastas quentes
de midia/documentos e saude fisica S.M.A.R.T.

--------------------------------------------------------------------------------
COMO UTILIZAR NO WINDOWS:
--------------------------------------------------------------------------------

ATENCAO: Antes de executar qualquer script, CERTIFIQUE-SE DE EXTRAIR O ARQUIVO .ZIP!
(Clique com o botao direito em Geio-DiskRadar-Windows-v2.2.0.zip -> "Extrair Tudo...")

OPCAO 1: GERAR O EXECUTAVEL VERSIONADO (.EXE)
  1. Dê dois cliques em:
       Compilar_EXE.bat
  2. O script detecta automaticamente o Python 3.14 (ou outra versao instalada),
     instala as dependencias e compila o binario final.
  3. O executavel final versionado sera gerado como:
       dist\DiskRadar-v2.2.0.exe
       DiskRadar-v2.2.0.exe (copia na raiz)
       DiskRadar.exe        (copia de conveniencia)
  4. Caso ocorra qualquer falha, o log completo e gravado em:
       compilacao.log

OPCAO 2: EXECUTAR DIRETO (SEM PRECISAR COMPILAR)
  1. Dê dois cliques em:
       Executar_DiskRadar.bat
  2. A interface gráfica do Geio DiskRadar v2.2.0 abre imediatamente.
  3. Log de execucao registrado em:
       execucao.log

--------------------------------------------------------------------------------
REQUISITOS NO WINDOWS:
--------------------------------------------------------------------------------
- Python 3.10, 3.11, 3.12, 3.13 ou 3.14 instalado.
- Conexao com a internet na primeira execucao (para baixar dependencias).

--------------------------------------------------------------------------------
GARANTIA DE SEGURANCA:
--------------------------------------------------------------------------------
- O Geio DiskRadar opera EXCLUSIVAMENTE em modo LEITURA (Read-Only).
- Nao formata, nao grava, nao modifica setores nem altera dados no disco.
